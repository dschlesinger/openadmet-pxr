# Better Baseline Method Report: OpenADMET PXR Induction Challenge

## 1. Overview

This repository documents the better baseline method used for the OpenADMET PXR induction challenge. The task is to predict compound activity, reported as `pEC50`, for the official test compounds.

The method follows a conventional cheminformatics machine-learning workflow. It combines molecular structure features, assay-derived auxiliary features, cross-validation, and model ensembling. The final output is a CSV file containing predicted `pEC50` values in the official submission format.

This version should be understood as a stronger baseline rather than a highly specialized model. Its main purpose is to use the available structure and assay information more completely than a simple single-model baseline.

## 2. Data Used

The method uses the official challenge-provided data, including:

- the training set with compound SMILES and observed `pEC50` values;
- the official test set with compound SMILES;
- available high-throughput screening response features;
- assay-derived auxiliary features from the primary assay and related counter-assay information.

No private, proprietary, or non-public external activity labels were used. The test-set activity labels were not used at any stage.

## 3. Molecular Standardization

The input molecular representation is based on canonical SMILES.

The preprocessing procedure includes:

1. reading the official training and test files;
2. parsing SMILES strings with RDKit;
3. converting valid molecules to canonical SMILES;
4. removing or safely handling invalid molecular records;
5. aligning feature matrices with the original compound order.

The purpose of this step is to make sure that the same compound has a consistent molecular representation and that all feature matrices match the official row order.

## 4. Feature Construction

The better baseline uses multiple groups of features.

### 4.1 Morgan Fingerprints

Morgan fingerprints are used to represent local circular substructures around atoms. They are useful because small changes in molecular substructures can strongly affect biological activity.

Typical settings include radius-based circular fingerprints and fixed-length bit vectors.

### 4.2 MACCS Keys

MACCS keys are compact binary structural keys. They encode the presence or absence of predefined chemical fragments. They are less detailed than Morgan fingerprints, but they provide a stable and interpretable structural baseline.

### 4.3 RDKit Descriptors

RDKit molecular descriptors are calculated to capture physicochemical and topological properties, such as molecular size, hydrophobicity, polarity, ring information, and other graph-based molecular properties.

These descriptors provide continuous molecular information that complements binary fingerprints.

### 4.4 HTS and Assay Auxiliary Features

The better baseline additionally uses high-throughput screening response features and assay-related auxiliary features when available.

These features are useful because PXR induction is a biological response. Structure alone may not fully capture this behavior. Previous assay response patterns can provide indirect information about whether a compound is likely to be active, inactive, noisy, or assay-interfering.

The auxiliary assay features are used only as predictors. They are not treated as hidden test labels.

## 5. Model Families

The baseline trains several standard regression models rather than relying on a single model. The main model families include:

- Random Forest regression;
- Extra Trees regression;
- Ridge regression;
- K-nearest-neighbor regression;
- optional gradient-boosting models when available in the environment.

Tree-based models are useful for nonlinear relationships between molecular features and activity. Ridge regression provides a simple linear reference model. K-nearest-neighbor regression provides a similarity-based reference model.

Using multiple model families reduces dependence on one modeling assumption.

## 6. Cross-Validation

The method uses cross-validation on the training set.

For each fold:

1. models are trained on the training portion;
2. predictions are generated for the validation portion;
3. predictions are generated for the official test set;
4. validation predictions are stored as out-of-fold predictions.

Out-of-fold predictions are important because they estimate how each model behaves on unseen compounds. They are also used to construct the final ensemble.

The validation metrics considered include:

- MAE;
- RMSE;
- R²;
- Spearman correlation;
- Kendall correlation.

## 7. Ensemble Strategy

The final prediction is generated by combining the predictions from several base models.

The better baseline uses out-of-fold predictions to estimate model weights. A simple average can be used, but the stronger version uses validation-based weighting, such as non-negative least squares or another constrained weighted average.

The ensemble is designed to give larger weights to models that perform better in cross-validation and smaller weights to weaker or unstable models.

After ensembling, predictions may be clipped to a reasonable `pEC50` range based on the observed training values. This avoids extreme predictions that are outside the activity range supported by the training data.

## 8. Difference from a Simple Baseline

Compared with a simple baseline, this better baseline has several improvements.

First, it uses more feature types. Instead of relying only on one fingerprint or one descriptor set, it combines structural fingerprints, molecular descriptors, and assay-derived features.

Second, it uses multiple model families. This makes the final prediction less dependent on one algorithm.

Third, it uses out-of-fold predictions to build an ensemble. This is more reliable than manually assigning model weights without validation evidence.

Fourth, it aligns training and test feature construction carefully, which reduces the risk of row mismatch, column mismatch, or inconsistent preprocessing.

## 9. Final Submission

The final output is a CSV file in the official submission format. It contains the required compound identifiers or SMILES columns, together with predicted `pEC50` values.

Before submission, the following checks are performed:

1. the number of rows matches the official test set;
2. required columns are present;
3. column names match the official format;
4. the row order is aligned with the official test file;
5. predictions are numeric and contain no missing values.

## 10. Reproducibility

The workflow can be reproduced using the following general steps:

1. install the required Python packages, including RDKit, NumPy, pandas, scikit-learn, and SciPy;
2. place the official data files in the expected data directory;
3. generate molecular features from canonical SMILES;
4. load and align available HTS and assay auxiliary features;
5. train base regression models with cross-validation;
6. save out-of-fold and test predictions;
7. build the validation-based ensemble;
8. export the final submission CSV.

## 11. Limitations

This method is a better baseline, not a final optimized solution.

The main limitations are:

- it depends on hand-crafted molecular features;
- the uncertainty of each prediction is not fully calibrated in the basic version;
- the model may perform worse for test compounds far from the training chemical space;
- assay-derived auxiliary features may contain noise or batch effects;
- cross-validation performance may not perfectly match blind leaderboard performance.

Future improvements could include explicit uncertainty quantification, applicability-domain modeling, conformal prediction, graph neural networks, multitask learning, and more careful treatment of assay noise.

## 12. Summary

The better baseline combines chemical structure features, assay auxiliary information, multiple regression models, cross-validation, and validation-based ensembling. It is intended to provide a stable and reproducible activity prediction pipeline for the OpenADMET PXR induction challenge.

The method uses only official challenge data and standard open-source cheminformatics and machine-learning tools.

# PXR Challenge - OpenADME Blind Challenge

My participation in the OpenADME PXR blind challenge - property prediction strand.

More info: https://openadmet.ghost.io/announcing-the-next-openadme-blind-challenge-predicting-pxr-induction/

## Why this project?

- Create an educational resource on ML for drug discovery
- Demonstrate my work process

## Technical setup

- Open software: RDKit, matplotlib, Chemprop, scikit-learn
- Work on marimo notebooks
- Use Claude Code to write code (not direct analysis)
- Blog: https://adlvdl.github.io/blog.html

## Workflow

1. **Data analysis & preprocessing** - explore SAR character, identify compounds to remove/alter, find public datasets for enhancement

2. **Generate data splits** - 5x5 cross-validated splits following Polaris group paper (random, scaffold, or time-based)

3. **Single-task baseline** - RF, XGB with different fingerprints, plus Chemprop

4. **Multi-task & finetuning** - leverage external data to improve predictions

5. **Analog set 1 predictions** - mid-challenge blinded set for prospective validation

6. **Analog set 2 predictions** - final ranking set
